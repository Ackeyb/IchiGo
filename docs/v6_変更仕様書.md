# IchiGo v6 変更仕様書

## 0. 文書の位置づけ

本書は、IchiGo v5 から v6 への変更仕様を定義する。

v6 では新しい Game Mode として **「ゼロワン」** を追加する。

ゼロワンは、ダーツのゼロワンを参考に、

- あらかじめ決められた残り点数から開始
- 各 player が 1 Turn につき 1 ROLL
- ROLL の結果に応じて残り点数と使用可能ダイス数を更新
- 残り点数をちょうど 0 にした player が Clear
- 全 player が Clear した時点で累積 Turn 数により順位決定
- 全員同 Turn 数なら Sudden Death

というルールで進行する。

v6 では既存 IchiGo の以下を再利用する。

- DiceResult
- scoring face semantics
- Throw Style
- OUT
- Renderer
- dice presentation
- Penalty presentation
- session recovery infrastructure

ただし Zero-One の Turn / Bust / Short / Clear / Ranking / Penalty semantics は独立した責務として扱う。

本書に明記されていない v5 の既存挙動は原則として維持する。

---

# 1. v6 の主変更

v6 では以下を追加する。

1. 新 Game Mode「ゼロワン」
2. 350 / 500 / 700 / 1000 の 4 preset
3. preset ごとの固定 Dice Count
4. 1 ROLL = 1 Turn
5. Bust
6. Short
7. Clear
8. Clean Clear
9. Turn Count Ranking
10. Zero-One Sudden Death
11. Turn差による Penalty Dice Count
12. Clean Clear 累積数による Penalty multiplier
13. Zero-One Recovery
14. Game Recovery schema 6

---

# 2. Setup — Game Mode

Setup の Game Mode 選択肢を以下の 4 つとする。

- ノーマル
- 完走指定
- 連続試合
- ゼロワン

ゼロワン選択時のみ、Zero-One preset 設定を表示する。

---

# 3. Zero-One preset

Zero-One では以下の 4 preset を選択できる。

| Preset | Start Score | Dice Count |
|---|---:|---:|
| 350 | 350 | 5 |
| 500 | 500 | 7 |
| 700 | 700 | 10 |
| 1000 | 1000 | 14 |

default：

**500 / 7 DICE**

---

# 4. Dice Mode の扱い

Zero-One では preset が Dice Count を決定する。

したがって既存 Dice Mode の 5 / 7 / 10 / 14 を別途選択させない。

Zero-One 選択時：

- Dice Mode 独立選択 UI は非表示または利用不可
- authoritative Dice Count は Zero-One preset から導出する

例：

500 preset
→ Dice Count = 7

---

# 5. mode 切替時の preset

Zero-One から別 mode へ切り替えた場合、
Zero-One 固有 preset は保持しない。

別 mode から Zero-One へ戻った場合：

**500 / 7 DICE**

へ初期化する。

同一 Zero-One mode を再選択しただけの場合は、
現在の preset を維持してよい。

---

# 6. Throw Style

Zero-One でも既存 Throw Style を使用する。

- rough
- normal
- careful

OUT probability も既存 semantics をそのまま使用する。

---

# 7. ROLL Limit

Zero-One では既存 ROLL Limit を使用しない。

Zero-One は：

**1 ROLL = 1 Turn**

であるため、各 Turn 内で複数回 ROLL しない。

Setup 上も Zero-One 選択時は ROLL Limit UI を非表示とする。

authoritative value は Zero-One Flow で参照しない。

---

# 8. scoring face

Zero-One の得点 face は既存 IchiGo と同じ。

- 1 = 100
- 5 = 50
- その他 = 0

同じ ROLL 内に複数の 1 / 5 が出た場合は、すべて得点する。

例：

1, 1, 5
→ 250 points

---

# 9. scoring dice removal

Zero-One では、その ROLL で得点したダイスを使用済みとして除外する。

例：

7 dice start
→ 1, 5, 2, 3, 4, 6, 2

score = 150
次回 Turn の active dice = 5

得点した 1 / 5 は次回 Turn では振らない。

---

# 10. OUT

Zero-One 本編で OUT は：

- score = 0
- そのダイスを除外
- 次回 Turn 以降は振らない
- Short reset まで復活しない

OUT check は既存どおり face 決定より先。

DieResult：

`{ status: "out", value: null }`

を維持する。

---

# 11. 1 ROLL = 1 Turn

Zero-One では、得点の有無に関係なく 1 ROLL でその player の Turn は終了する。

したがって：

- score が出ても続けて ROLL しない
- score 0 でも Turn 終了
- OUT のみでも Turn 終了
- Bust でも Turn 終了
- Short でも Turn 終了
- Clear でも Turn 終了

---

# 12. Turn count

player ごとに累積 Turn Count を持つ。

ROLL を実行した時点で、その player の Turn Count を必ず +1 する。

以下すべて 1 Turn と数える。

- 通常 ROLL
- score 0
- OUT
- Bust
- Short
- Clear

Clear した Turn 自体も Turn Count に含める。

---

# 13. player state

Zero-One の player state は少なくとも以下を持つ。

- player identity
- remainingScore
- activeDice
- stranded / removed equivalent state
- accumulatedTurnCount
- isCleared
- currentRunHadBustOrShort
- 必要に応じて Turn snapshot

具体的型は既存 architecture に合わせる。

不要な duplicate authority は追加しない。

---

# 14. state carry

Zero-One では、player の状態を次回自分の Turn へ持ち越す。

例：

500 / 7 DICE

Turn 1：
- score 150
- remainingScore 350
- activeDice 5

次回 Turn は：

- remainingScore 350
- activeDice 5

から開始する。

---

# 15. Turn snapshot

Bust rollback のため、ROLL 開始直前にその player の Turn 開始 state を snapshot する。

snapshot の対象：

- remainingScore
- activeDice
- OUT / removed dice state
- その他 Turn 中に変化する Zero-One player state

Turn Count は rollback 対象外。

---

# 16. result evaluation priority

Zero-One の ROLL 後判定優先順位は以下とする。

1. Clear
2. Bust
3. Short
4. Normal Turn End

この順序を崩さない。

---

# 17. Clear

ROLL 後の score 減算結果が：

`remainingScore === 0`

なら Clear。

Clear は最優先。

同じ ROLL で activeDice が 0 になっても、remainingScore が 0 なら Short ではなく Clear。

---

# 18. Bust

ROLL score が remainingScore を超える場合：

`rollScore > remainingScore`

Bust。

例：

remainingScore = 50
ROLL score = 100

→ Bust

---

# 19. Bust rollback

Bust 時は、その Turn の結果をすべて無効とする。

Turn 開始 snapshot へ完全 rollback する。

rollback 対象：

- remainingScore
- scoring dice removal
- OUT removal
- active dice state
- その他その Turn 中に変化した player state

rollback しないもの：

- accumulatedTurnCount
- cleanClearEligible = false

---

# 20. Bust example

Turn 開始：

- remainingScore = 100
- activeDice = 3

ROLL：

- 1
- OUT
- 5

rollScore = 150

→ Bust

結果：

- remainingScore = 100 に戻す
- activeDice = 3 に戻す
- OUT もなかったことにする
- Turn Count +1を維持し、cleanClearEligible = false

---

# 21. Short

Short は、

**現在残っている active dice では、remainingScore を理論上 0 まで到達させられない状態**

である。

1 die の最大得点は 100。

したがって Short 条件は：

`remainingScore > activeDice * 100`

とする。

---

# 22. Short example

remainingScore = 300<br>
activeDice = 2

最大得点：

200

したがって：

300 > 200

→ Short

---

# 23. activeDice 0

remainingScore > 0
かつ
activeDice = 0

なら Short。

---

# 24. Short 判定 timing

最終 semantics は：

**Clear → Bust → Short**

を守る。

ROLL 後に得点・除外状態を評価し、Clear / Bust でなければ更新後 state に対して Short を判定する。

---

# 25. Short reset

Short が確定したら、その player のみ初期状態へ reset する。

reset：

- remainingScore = preset start score
- activeDice = preset dice count
- OUT / removed dice を全復活
- cleanClearEligible = false（Short reset後も資格を復活させない）

維持：

- accumulatedTurnCount
- player identity
- global Clean Clear count
- player order

---

# 26. Short は rollback ではない

Bust と Short を混同しない。

Bust：

Turn 開始 state へ rollback。

Short：

その player を preset 初期状態へ reset。

---

# 27. Normal Turn End

Clear / Bust / Short のいずれでもない場合：

- remainingScore を更新
- scoring dice removal を維持
- OUT removal を維持
- Turn 終了
- 次 player へ

---

# 28. No Score

ROLL score = 0
かつ
Bust / Short / Clear でない場合：

単純に Turn 終了。

IchiGo Normal のような同 Turn continuation は行わない。

---

# 29. player order

Setup の original player order を使用する。

各未 Clear player が 1 Turn ずつ交代する。

Clear 済み player は以後 Turn を行わない。

---

# 30. Clear 後

player が Clear したら：

- isCleared = true
- 以後 ROLL しない
- accumulatedTurnCount を固定
- remaining players のみで進行

---

# 31. game end

Zero-One の通常 Game は：

**全 player が Clear**

した時点で終了。

途中で leader が Clear しても Game 自体は終了しない。

---

# 32. Ranking

Zero-One Ranking は：

**accumulatedTurnCount ASC**

で決定する。

少ない Turn 数で Clear した player が上位。

---

# 33. tie

同じ Turn Count で Clear した player は同順位。

実時間上どちらが先に Clear したかは順位に影響しない。

competition ranking を使用する。

例：

A = 4<br>
B = 6<br>
C = 6

順位：

A = 1位<br>
B = 2位<br>
C = 2位

B / C が同率最下位。

---

# 34. loser

lowest rank の player 全員が loser。

複数 loser を許可する。

---

# 35. all tied

全 player の accumulatedTurnCount が完全に同じ場合：

全員同順位。

この場合は Penalty へ進まず Sudden Death。

---

# 36. Zero-One Sudden Death

全員同 Turn Count の場合、全員で Zero-One を最初からやり直す。

reset：

- remainingScore = preset start score
- activeDice = preset dice count
- removed / OUT state
- isCleared
- currentRunHadBustOrShort

維持：

- original player order
- preset
- Throw Style
- accumulatedTurnCount
- global Clean Clear count

---

# 37. Sudden Death Turn count

Sudden Death でも accumulatedTurnCount は reset しない。

そのまま累積。

---

# 38. Sudden Death の繰り返し

Sudden Death 後も全員同 accumulatedTurnCount なら、再度 Sudden Death。

回数上限なし。

---

# 39. Clean Clear

Clean Clear は、

**そのRound開始からClearまで、一度もBustもShortもしていないClear**

と定義する。

---

# 40. Clean Clear に影響しないもの

以下は Clean Clear 資格を失わせない。

- score 0
- OUT
- 通常 ROLL
- active dice reduction
- long run

BustまたはShortが一度でも発生したら、そのRound中はClean Clear資格を失い、Short reset後も復活しない。

---

# 41. Clean ClearのRound境界

Clean Clear資格は以下のRound開始時に全player trueへresetする。

- initial Game start
- Sudden Death start

Bust / Shortでfalseとし、ShortはScore / Diceだけをresetする。Short後のやり直しをノーミスClearしても同Round内ではClean Clearではない。獲得済みtotalCleanClearCountは維持する。

---

# 42. Sudden Death での Clean Clear 資格

Sudden Death 開始時には、全 player の current run qualification を reset する。

したがって本戦で Bust / Short を経験した player でも、

Sudden Death run を Bust / Short なしで Clear すれば Clean Clear を獲得できる。

---

# 43. Clean Clear count

Clean Clear が発生するたびに、

global：

`totalCleanClearCount`

を +1 する。

Penalty multiplier 用の global count とする。

---

# 44. Clean Clear count carry

以下を跨いで累積する。

- player 間
- Short reset
- Sudden Death
- repeated Sudden Death

Game 全体を通して保持。

---

# 45. Penalty multiplier

Zero-One Penalty multiplier：

`totalCleanClearCount + 1`

---

# 46. Penalty Dice Count

Zero-One の loser 1人あたり Penalty Dice Count は：

`loserTurnCount - topTurnCount`

とする。

preset Dice Count は掛けない。

---

# 47. Penalty example

500 / 7 DICE

A = 4 Turn<br>
B = 7 Turn<br>
C = 7 Turn

topTurnCount = 4<br>
loserTurnCount = 7

Penalty Dice Count：

3

B / C はそれぞれ 3 dice Penalty。

---

# 48. Penalty chunking

Penalty Dice Count が 10 を超える場合：

最大 10 dice ずつ chunk 化する。

例：

23 dice
→ 10 + 10 + 3

既存 Series Penalty の chunk infrastructure を再利用してよい。

---

# 49. Penalty interaction

loser 1人につき：

- 最初の Penalty ROLL は user tap
- subsequent chunks は既存 auto sequencing を利用可能
- 1 loser 完了後、次 loser は user tap

---

# 50. Penalty OUT

Penalty 中の OUT は既存 Penalty semantics を使用する。

表示：

OUT

authoritative DieResult：

`status = out`
`value = null`

BASE 計算上のみ：

OUT = 6

---

# 51. Penalty BASE / FINAL

各 Penalty chunk の結果を BASE に加算。

全 chunk の BASE 合計に対し、
multiplier を 1 回だけ適用。

`FINAL = totalBASE * (totalCleanClearCount + 1)`

---

# 52. Penalty UI

Zero-One Penalty は既存 Series Penalty UI を再利用してよい。

running：

- current loser
- total penalty dice
- chunk progress
- current chunk dice result
- cumulative BASE

resolved：

- total BASE
- multiplier
- final penalty points

既存方針どおり per-chunk BASE subtotal は表示しない。

---

# 53. Zero-One progress UI

Play 画面では最低限、current player について以下を表示する。

- player name
- remainingScore
- activeDice
- accumulatedTurnCount
- preset

必要に応じて全 player の進行一覧を表示してよい。

---

# 54. provisional ranking

Zero-One は全員 Clear 前でも accumulatedTurnCount を持つが、
未 Clear player の最終順位は確定しない。

未 Clear player を確定順位として扱わない。

---

# 55. cleared player display

Clear 済み player は：

- Clear
- final Turn Count

が分かる表示とする。

以後 ROLL 対象にしない。

---

# 56. Turn indicator

Zero-One では ROLL Limit counter は使用しない。

accumulated Turn Count を表示してよい。

---

# 57. Zero-One button

current player が active の場合：

ROLL

button を使用。

1 tap で 1 Turn。

同じ Turn 内に continuation ROLL button を出さない。

---

# 58. Bust presentation

Bust が発生した場合：

- ROLL result は表示
- Bust であることを user に明示
- authoritative state は Turn snapshot へ rollback
- 次 player へ進む

visibleState / staged presentation を既存 contract に従って扱う。

---

# 59. Short presentation

Short が発生した場合：

- ROLL result を表示
- Short であることを明示
- reset 後 state は authoritative に反映
- 次回その player は preset 初期状態

Short 前の結果と reset がユーザーに理解できること。

---

# 60. Clear presentation

Clear が発生した場合：

- ROLL result
- Clear
- Turn Count

を表示。

Clean Clear の場合は、内部で totalCleanClearCount を +1。

---

# 61. final ranking

全 player Clear 後、
all tied でなければ Final Ranking へ進む。

表示：

- rank
- player
- accumulatedTurnCount

loser を明確化。

---

# 62. all tied detection

全 player の accumulatedTurnCount が同値なら：

Penalty へ進まず Sudden Death。

Action：

**「サドンデスへ」**

---

# 63. Replay

Zero-One Replay では：

固定：

- Game Mode = Zero-One
- preset
- Dice Count derived from preset
- Throw Style

order のみ編集可能。

progress reset：

- remainingScore
- activeDice
- Turn Count
- Clear state
- Clean Clear count
- Sudden Death state
- Penalty state

---

# 64. New Game

New Game は Zero-One mode / preset / Throw Style を Setup へ carry。

progress は carry しない。

---

# 65. Full Reset

Full Reset は v5 contract を維持。

- Normal
- 7 DICE
- normal throw
- ROLL ∞
- 2 blank players

Zero-One を default mode にしない。

Sound は維持。

---

# 66. Recovery schema 6

Game Recovery schema：

**6**

へ更新する。

schema 5 以下は unsupported。

migration しない。

# 67. Sound schema

Sound schema：

**1**

を維持。

Game schema 6 と独立。

# 68. Recovery — Zero-One saved state

最低限保存する。

- mode = Zero-One
- preset
- Throw Style
- player order
- per-player remainingScore
- per-player active / removed / OUT state
- per-player accumulatedTurnCount
- per-player isCleared
- per-player current run Bust/Short qualification state
- totalCleanClearCount
- current player
- Sudden Death state
- Penalty progress
- committed Penalty chunks
- staged presentation に必要な既存 authoritative state

---

# 69. Recovery — committed roll

Zero-One ROLL は：

authoritative commit
→ save attempt
→ presentation

の順を維持。

Recovery 後に同じ ROLL を再抽選しない。

---

# 70. Recovery — Bust

Bust が authoritative に確定済みなら、
Recovery 後も rollback 後 state を復元する。

Bust ROLL を再抽選しない。

---

# 71. Recovery — Short

Short が authoritative に確定済みなら、
Recovery 後は reset 済み player state を復元する。

再抽選しない。

---

# 72. Recovery — Clear

Clear が committed 済みなら：

- isCleared
- Turn Count
- totalCleanClearCount

をそのまま復元。

Clean Clear count を二重加算しない。

---

# 73. Recovery — Sudden Death

Sudden Death 中：

- accumulatedTurnCount を保持
- totalCleanClearCount を保持
- current run qualification を Sudden Death start state から復元
- preset / player order を保持

---

# 74. Recovery — Penalty

Zero-One Penalty は既存 Series Penalty Recovery infrastructure を再利用してよい。

ただし Penalty Dice Count の算出根拠は Turn difference。

committed chunks を再抽選しない。

---

# 75. schema 5 migration 禁止

禁止：

- schema 5 state を schema 6 として解釈
- missing preset を 500 と推測
- missing Turn Count を 0 と推測
- corrupt Zero-One state を repair

unsupported / invalid path を使用。

---

# 76. invariant

Zero-One では preset Dice Count を `diceCount` とした場合、
既存 state model に合わせた dice invariant を維持する。

Short reset 後：

active = diceCount

ただし Clear / Bust より後に適用する。

# 119. v6 要約

## Zero-One preset

- 350 / 5 DICE
- 500 / 7 DICE
- 700 / 10 DICE
- 1000 / 14 DICE

default：

500 / 7 DICE

## Turn

1 ROLL = 1 Turn。

score が出ても同 Turn 内で続けない。

## scoring

1 = 100<br>
5 = 50

scoring dice は除外。

OUT：

0 points + 除外。

## Bust

残り点数を超えたら Bust。

Turn 開始 state へ rollback。

Turn Count は +1 のまま。

## Short

`remainingScore > activeDice * 100`

なら Short。

その player だけ：

- preset score
- full dice

へ reset。

Turn Count は維持。

## Clear

remainingScore = 0。

Clear player は以後 Turn なし。

## Ranking

全員 Clear 後、

Turn Count ASC。

同 Turn Count は同順位。

lowest rank 全員 loser。

全員同 Turn Countなら Sudden Death。

## Sudden Death

score / dice / Clear state を初期化。

Turn Count は累積。

Clean Clear count も累積。

run qualification は reset。

## Clean Clear

そのRound開始からBust / ShortなしでClear。Short resetでは資格は復活せず、Sudden Death開始時に全playerの資格をresetする。

発生ごとに：

`totalCleanClearCount + 1`

Penalty multiplier：

`totalCleanClearCount + 1`

## Penalty

Penalty Dice Count：

`loserTurnCount - topTurnCount`

preset Dice Count は掛けない。

10超は chunk。

Penalty OUT：

表示 OUT / 計算 6。

## Recovery

Game schema：

6

schema 5以前：

unsupported / migrationなし

Sound schema：

1 のまま
